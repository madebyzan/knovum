# Knovum 0.4.1

This release turns the empty conversation into an inspector launchpad, scopes the document source reader to the tab you are editing, and corrects the workspace tab strip, the writing menu's model choice, the diarization control and the canvas background popover.

An empty Conversation no longer offers a short list of prompts. It now follows the same borderless inspector-section rhythm as the workbench sidebars: a summary of what the Space holds, counted across notes, documents, websites, media and objects; starter prompts that fill and focus the composer without sending; quick-attach rows for the live sources in that Space; and your recent conversations for one-click resumption.

The Source Reader opened from a document editor belongs to that tab now. It previously read the canvas's shared reading session, so one tab could display a source another tab opened, and its back and forward buttons walked canvas history. Each editor tab keeps its own target, a splitter rail sets the division between the editor and the reader, and the width stays inside the same 25–68% range the canvas reader clamps to.

The editor writing menu offers one model selector: writing and translation both run on the execution route you pick there, instead of each holding a separate choice. The diarization control drops its manual speaker-count field; detection is automatic, and the row keeps the model menu and generate action on the shared button style.

Opening or resizing the right context pane no longer compresses the workspace tab strip. The tab column spans the window up to the compact trailing utility cluster and flexes smoothly down to a readable minimum before it scrolls, with New Space staying pinned beside the strip.

The canvas background control fans its three patterns — dots, grid, none — out along an equidistant quarter-circle arc from its toolbar icon, with staggered transitions that fall back under reduced motion and arrow-key traversal between the choices.
