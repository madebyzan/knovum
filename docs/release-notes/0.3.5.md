# Knovum 0.3.5

This release rebuilds the speech pipeline end to end, refreshes the image model lineup and makes credential entry behave like a professional desktop app.

Vocal and accompaniment separation now runs Meta's HTDemucs on the GPU (Metal or Vulkan, CPU as fallback) instead of Spleeter. Sources up to six hours are processed in overlapping blocks, so memory stays flat and long videos no longer fail at the final mix. Dubbing reuses a separation only when it matches the current video and model.

Voice cloning gains three new families — IndexTTS2, Qwen3-TTS and Fun-CosyVoice3 — beside VoxCPM2, all cloning from a short reference recording. VoxCPM2's most precise mode now actually uses the reference transcript. A new one-click path clones the original speakers of a video: the selected clip is separated first so the clone carries the voice alone, without music or effects, and each detected speaker is offered with their longest clean turn.

Dubbing never cuts a word again. A line is compressed up to 1.25× to fit its subtitle window, then speaks into the silence before the next line; if it still does not fit, it is heard whole and the next line waits. IndexTTS2 can render to an exact duration, so overrunning lines are regenerated to fit instead of retrying random seeds. Publication also respects the source video: HEVC is tagged so QuickTime, Safari and iOS accept it, and codecs MP4 cannot hold (such as ProRes) are encoded to H.264 instead of failing the whole dub.

Transcription adds Qwen3-ASR 1.7B beside Whisper, stronger on Chinese and Chinese-English speech. Whisper remains the default, so existing libraries are unchanged.

Image tools move to current state-of-the-art models: background removal offers six choices led by BiRefNet General Lite and RMBG-2.0 (U²-Net is retired), smart selection uses MobileSAM for speed and SAM 2.1 Hiera-Tiny for quality, and repair is Big LaMa only. Depth and upscaling keep Depth Anything V2 and Real-ESRGAN after benchmark review.

Every credential field — object storage, AI connections, canvas and connector authorization — is now one professional secure input: the stored value loads into the field, revealing shows the real value and keeps it editable, and clearing removes the secret. Object storage gains a working "Test connection" that can be used before saving.
