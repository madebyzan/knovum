# Knovum 0.2.0

This release keeps answers on the canvas with the sources they cite, reads the text inside your
pictures on this computer, and opens a PDF at the passage an answer cited.

When an answer matters, its action row adds it to the canvas as a Markdown item. Selecting a
passage opens a bar to save it as a Sticky Note, copy it, or quote it into the input for a
follow-up. What you keep does not sit alone on the canvas: it links to every live item cited in
the blocks it touches and takes its place to the right of those sources, and saving and linking
are one undo step whose confirmation offers Show. A selected passage can be dragged onto the
canvas with the mouse. Dragging inside the window is now one pointer gesture everywhere, so video
materials also land on the timeline where you drop them instead of nowhere.

A kept note remembers the passage and revision of every source it cites. When a source moves on,
the note shows a source-updated badge and its inspector lists the changed sources: open one to
compare, or mark it reviewed to keep the note as it is. Nothing is rewritten for you.

Text recognition runs on this computer. Scanned and rendered PDF pages, pictures inside documents,
screenshots and photos are read by a pinned local model on the existing inference worker, in the
background; nothing is sent to a cloud service. Recognized text belongs to the picture it was read
from and joins the node's source passages with that picture's own locator, so answers cite
recognized text like any other passage and the Inspector shows it per picture. A picture is read
as rendered, at its visual revision, so an edit or a new video cover is read again.

The in-app PDF reader opens from the Inspector, or from a cited passage at the cited page with the
passage highlighted, so checking a citation no longer means leaving Knovum or finding the page
yourself.

On the first launch of a library, Knovum imports a sample Space in the interface language through
the ordinary import: a fictional brief whose third page is a scan, a whiteboard photo, and notes
that walk through the reader, text recognition and cited answers, so there is something real to
try before your own material arrives.
