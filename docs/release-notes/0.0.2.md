# Knovum 0.0.2

This release hardens Space indexing, conversations, and the Windows desktop.

Indexing a Space is now one cancellable job in the Task Center. A rebuild indexes the gap instead of
the whole Space, and the live index stays readable while the rebuild runs. Agents learn the citation
marker the reader resolves, and index state is measured against the spec in force.

Conversations gain a producing status, one owner writes the words of a run, and a block boundary now
separates a streaming answer instead of erasing it. The voice library can be heard before it is
chosen and draws the voice that is speaking.

On Windows the app ships an opaque window with the WebView2 bootstrapper embedded, and startup
failures are revealed instead of leaving a hidden window. The main window is revealed from the async
runtime. Local models state the hardware they were qualified on and no longer veto a download over
installed memory; the check admits memory the OS can allocate.

A document larger than the enrichment budget is truncated at the budget instead of being refused.
The Task Center lists work that has nowhere else to be watched. Committing actions use the solid
neutral button rather than brand blue. Enrichment tasks and the sync inbox title are localized.
Shipped schemas are frozen: persisted data moves forward with the next numbered migration, never by
resetting a library.
