# Knovum 0.3.2

This release introduces fully customizable keyboard shortcuts across the application, improves global dictation stability and audio resampling for on-device Whisper models, updates README artwork and assets, and adds environment configuration guidance for network mirror endpoints.

A dedicated Keyboard Shortcuts settings pane is now available under General Settings. You can customize, record, and reset keybindings for navigation, tools, canvas manipulation, and system commands, complete with real-time key chord recording and conflict detection across all 11 supported interface languages.

System-wide push-to-talk dictation gains resilient, non-panicking global shortcut registration to prevent startup exit conflicts on Windows. The underlying native audio capture pipeline now automatically resamples live microphone inputs to 16 kHz mono for optimal Whisper speech recognition accuracy.

In addition, the project documentation and README visual assets have been refreshed with updated branding banners, high-resolution canvas workflow diagrams, and troubleshooting instructions for configuring HuggingFace mirror endpoints (`HF_ENDPOINT`).
