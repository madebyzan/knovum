# Knovum 0.3.1

This patch release fixes external Agent execution on macOS when launched as an installed desktop application, resolves node package runner paths explicitly, and improves error feedback for missing runtime dependencies.

When Knovum is launched from macOS Finder or the Dock, external Agent adapters (such as Claude Code and Codex CLI) now properly inherit the user's interactive login shell environment, ensuring toolchains and version managers configured in `~/.zshrc` (including fnm, nvm, mise, asdf, and Homebrew) are discovered accurately.

In addition, the Node package runner (`npx`) is now resolved to an explicit absolute path across platforms, avoiding failure modes with relative command resolution under isolated launch environments, and surfaces clear, actionable guidance if Node.js is not yet installed.
