# Knovum 0.2.1

This release brings dedicated rich representations for web and social links on the canvas, refines text typography and scaling, and relicenses Knovum under the MIT License.

Web links and social content dropped onto the canvas now render with specialized presentation cards. GitHub repositories show repository identity, descriptions, and metadata, while Twitter/X posts display author identity and post context directly on the canvas. When media acquisition for multi-modal links cannot extract a playable stream, capture automatically falls back to an enriched website card so your research materials always land on the canvas rather than failing.

Canvas typography has been refined for better visual density and scaling. Text elements adopt an updated size scale spanning from 9 to 144 points with a tighter default base size of 10, bringing note and card readability into balance with surrounding canvas media. Multi-language sample Spaces have been updated to reflect these typography improvements.

Knovum is now distributed under the MIT License, clarifying open-source reuse across the application, Rust crates, and Python runtimes.
