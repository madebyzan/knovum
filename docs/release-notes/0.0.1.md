# Knovum 0.0.1

This release establishes the signed application-update baseline for direct desktop distribution.
Knovum checks for updates in the background and offers reviewed release notes in About. Downloads
show progress in Task Center and can be cancelled. Installation is explicit and requires saved changes
and no running background tasks. Update packages are verified before installation.

The permanent update channel separates discovery from artifact storage, allowing approved signed
packages to move between GitHub Releases and another HTTPS host without reinstalling the client.
Upgrading from an updater-disabled internal QA build requires installing this baseline normally.
