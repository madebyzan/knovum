# Knovum 0.3.4

This release widens the provider and desktop-agent lineup and gives cloud-generated media one user-owned delivery path.

More providers are available out of the box: Perplexity, Cohere, Baidu, Hunyuan, Baichuan, SenseNova, Spark, Cerebras, Fireworks and LM Studio join the routing options. Hunyuan runs through Tencent TokenHub for image and video generation, and DeepSeek gains vision. Capabilities are wired against vendor documentation — OpenRouter image and video, xAI Grok video, Kling, Together, DashScope and MiniMax — while retired or unavailable ones are no longer offered: StepFun image and video and OpenAI video are removed, and an OpenAI-compatible vendor can no longer expose image generation it has not declared. Desktop agents add the separate Qoder and QoderCn kinds with their logos, and the agents toggle now reflects whether a usable command was actually detected, showing connection help when the check fails.

Cloud-model media follows a single delivery rule through a new Object Storage settings pane. Configure an S3-compatible endpoint, region, bucket and public base URL, test the connection, and edits save automatically. Generated images and video are uploaded there and shared by public URL when storage is configured, and fall back to inline data when it is not. Credentials are kept in the dedicated secrets store rather than in settings, and the previous per-provider upload shortcuts are gone.

Settings overlays also stay visible regardless of the workspace's active state, so connection help and dialogs remain usable while you work in Settings.
