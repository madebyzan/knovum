# Knovum 0.3.7

This release adds an interactive canvas mini map, fixes rich-text rendering mismatches between document tabs and canvas cards, and brings dependencies and security advisories up to date.

The canvas now includes a collapsible mini map in the bottom-right corner. It stays collapsed by default to preserve canvas space, expands on click with a smooth transition, and lets you inspect node layout and drag or click the viewport frame to navigate large workspaces directly.

Rich-text cards on the canvas now share the exact same ProseMirror and Tiptap schema as full document tabs. Headings, code blocks, horizontal rules, highlights, embedded images (`asset:` URIs), subscripts, superscripts, tables, and font-size marks render reliably on the canvas without `Node.fromJSON` schema errors.

Plugin Git fetching upgrades `gix` to `0.90.0`, alongside dependency security updates across the Rust, Python, and Web toolchains.
