# Action triage

Read when translating a decision, transcript or brief into tracked work.

Separate decided actions from suggestions and open questions. A useful issue has one outcome, bounded scope, evidence, and observable acceptance criteria. Split independent outcomes only when they can be completed independently; do not create a task for every sentence.

Resolve the team/project and inspect current workflow states. Preserve existing work and check duplicates. Owner, priority, milestone and deadline must come from explicit instruction or confirmed source evidence; otherwise leave them unset. Completing an issue requires evidence of the intended outcome, not the existence of a discussion.

After writes, verify the returned issue identity and relevant fields. Link each issue to its supporting Space source or meeting timestamp. State unresolved access or missing fields explicitly rather than silently publishing incomplete substitute work.
