# Retrieval practice

Read when creating questions or a review plan.

A useful learning objective states what the learner can explain, distinguish or apply. Make each question test one objective. Open recall should come before answer options; plausible distractors must represent meaningful distinctions, never arbitrary trivia. Include application questions only when the source supports the situation and answer.

Separate questions from the answer key. Each answer includes a source locator, explanation and the misconception the question addresses. If more than one answer is defensible, acknowledge that rather than marking the learner wrong.

A review plan can suggest revisiting difficult ideas after a day, a few days and a week, adapting to actual recall. These are suggested intervals, not a scientifically personalized schedule or an installed reminder. Prioritize what the learner missed instead of reassigning all material.

Check that every objective is covered, every answer is supported, the guide adds organization rather than duplicating the whole source, and no invented scores or external knowledge appear as source facts.
