# Transcript review

Read when the transcript is ambiguous, speaker attribution matters, or actions must be extracted.

Keep the original timestamp interval and source revision for decisions and actions. Use the transcript's explicit speaker labels; a guess at a person's identity must never become an owner. Unclear speech stays unclear. Summaries should not turn a proposal into agreement or a discussed date into a deadline.

Separate: decided, proposed, disputed, and unresolved. An action needs an explicit task; record owner and due date only if stated. Resolve pronouns from nearby transcript context; if unresolved, leave the reference explicit rather than inventing it.

Meeting notes prioritize decisions and tasks. Interviews preserve each speaker's position and meaningful qualifications. Lectures organize concepts and explanation, then questions answerable from the recording. Read the relevant segments for each output item; topic labels alone are insufficient evidence.

Before delivery: verify every decision/action against the original segment, ensure no missing qualification reverses the meaning, and identify the source and covered recording interval.
