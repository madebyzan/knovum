04 从源代码构建

更喜欢自己构建？

Knovum 基于 MIT 许可证开源。仓库文档提供了工具链与构建流程。

阅读安装要求
Terminal 
$ git clone https://github.com/madebyzan/knovum.git
$ cd knovum
$ corepack enable
$ pnpm install --frozen-lockfile
$ pnpm desktop:dev

工具链要求：Node.js 22.13+、Corepack、项目固定的 Rust 工具链、uv、CMake、Protobuf 与 LLVM/libclang。

05 下载相关问题

开始之前，你可能想知道。

更多细节可以在项目文档中找到。

浏览项目文档
Knovum 免费吗？

是的。Knovum 是基于 MIT 许可证发布的免费开源软件。

需要 AI 服务账号吗？

使用 Knovum 及其本地功能不需要账号。云端 AI 问答与生成需要连接你选择的模型服务。

为什么模型需要单独下载？

本地能力会在首次需要时下载对应模型。这样可以减小初始安装体积，也允许你在不再需要时从设置中移除模型。

支持 Linux 吗？

当前版本暂不支持 Linux 与 Windows ARM。最新支持的安装包请以版本发布页面为准。

为什么 macOS 提示已阻止 Knovum？

当前版本尚未通过 Apple 公证或 Authenticode 签名，首次打开时 macOS 会请你确认。之后的更新会在应用内交付，并根据版本签名进行验证。

打开「系统设置 → 隐私与安全性」，找到被阻止的 Knovum 条目并点击「仍要打开」，再输入管理员密码确认。之后即可直接启动。
