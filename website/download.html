03BEFORE YOU INSTALL

A transparent note about first launch.

Current builds are not yet notarized by Apple or Authenticode-signed. macOS and Windows may ask you to confirm the first launch. Updates after that are delivered in the app and verified against the release signature.

FIRST LAUNCH

Only download installers from the official Knovum GitHub releases page. Check that the asset matches your operating system and processor architecture.

04BUILD FROM SOURCE

Prefer to build it yourself?

Knovum is open source under the MIT License. The repository documents the toolchain and build process.

Read installation requirements↗
TERMINAL 
git clone https://github.com/madebyzan/knovum.git
cd knovum
corepack enable
pnpm install --frozen-lockfile
pnpm desktop:dev

Toolchain: Node.js 22.13+, Corepack, the pinned Rust toolchain, uv, CMake, Protobuf, and LLVM/libclang.

Browse documentation↗
Is Knovum free?

Yes. Knovum is free and open-source software under the MIT License.

Does it need an AI account?

No account is needed for Knovum or its local capabilities. Cloud AI answers and generation need a model connection you choose.

Why are models downloaded separately?

On-device capabilities download their model files when first needed. This keeps initial installation smaller and lets you remove models from Settings when you no longer need them.

Is Linux supported?

Linux and Windows on ARM are not supported by the current release. See the release page for the latest supported installers.
